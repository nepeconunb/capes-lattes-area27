# Política de Privacidade — CAPES-Lattes 2.0

## Escopo
A extensão processa páginas de Currículo Lattes abertas pelo usuário.

## Dados tratados
- Texto bibliográfico da seção “Artigos completos publicados em periódicos”.
- Nome e ID Lattes para identificação do painel.
- Nome do periódico para fins de classificação.
- Dados de classificação e gráficos do último CV analisado.

## Armazenamento
Os dados do último currículo analisado são armazenados localmente no navegador por meio do armazenamento da extensão.

## Consultas externas
Quando necessário, a extensão pode consultar fonte pública externa usando apenas informações necessárias à busca do periódico, como seu nome.

## Não realizado
- Não envia o currículo completo para servidor próprio.
- Não vende dados.
- Não utiliza dados para publicidade.
- Não cria perfil comercial do usuário.

## Aviso institucional
A extensão é independente e não é produto oficial da CAPES ou do CNPq.
