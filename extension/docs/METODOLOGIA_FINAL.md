# Metodologia final — CAPES-Lattes 2.5.1

1. A extensão lê apenas a seção “Artigos completos publicados em periódicos”.
2. Livros, capítulos de livros e outras produções são excluídos.
3. O Qualis Referência 2017–2020 é apresentado como benchmark longitudinal para todos os anos.
4. O seletor contém todas as áreas CAPES cadastradas.
5. A regra atual MB/B/R/F/NC está implementada apenas para a Área 27.
6. Para outras áreas, a extensão não replica a regra da Área 27.
7. Quando uma base histórica específica de outra área é importada, ela pode complementar ciclos anteriores.
8. Quando não há evidência suficiente, o resultado é ND/NC, conforme o sistema, sem inferência automática.

Essa separação evita confundir:
- Qualis histórico;
- benchmark longitudinal;
- classificação atual;
- critérios específicos de cada área.
