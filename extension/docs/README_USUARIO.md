# CAPES-Lattes 2.0

## Instalação piloto
1. Descompacte o arquivo ZIP.
2. No Chrome, abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta que contém `manifest.json`.
6. Abra qualquer Currículo Lattes.

## Uso
- O cartão CAPES-Lattes aparece no cabeçalho do CV.
- Clique em **Ver gráficos** para abrir o painel no próprio Lattes.
- Selecione o período desejado.
- A lista exibe apenas artigos completos publicados em periódicos.

## Importante
Esta ferramenta é independente e não é produto oficial da CAPES ou do CNPq.
